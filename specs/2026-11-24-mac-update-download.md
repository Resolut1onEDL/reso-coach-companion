# На маке карточка «Обновление» предлагает «Скачать», а не показывает ошибку подписи

Запрос: основатель, 24.11, скриншот своего мака: в карточке «Обновление» — «ошибка: Code signature at URL file:///…/Reso%20Coach%20Companion.app/ did not pass validation: code has no resources but signature indicates they must be present»; на вопрос «Чинить на маке экран обновления: кнопка «Скачать» вместо ошибки?» — «Да, чини».
Оценка: мини-спека багфикса.

Зачем: мак-сборка не подписана, и Squirrel.Mac не ставит её обновление (`specs/2026-11-04-update-nudge.md`), но `autoUpdater.autoDownload = true` качает его и на маке — игрок видит сырую ошибку вместо пути к новой версии.
Кто: игрок с маком, когда выходит новая версия (кнопка «Проверить» или проверка в фоне).
Готово, когда: на маке обновление не качается само; карточка пишет «доступна v<версия>» и показывает кнопку «Скачать», она открывает страницу последнего выпуска (как уже делает «Обновить» в уведомлении). На Windows и Linux всё как было: качается само, «Перезапустить и установить».
Похоже на: `installUpdate()` в `src/main.js` — на маке уже открывает `RELEASES_URL`; та же карточка `#updateCard` в `src/index.html`.
Не делаем: подпись сборок (TODO.md «Подпись Reso Coach Companion»); обновление без браузера.
Уже есть: уведомление при запуске Доты (`update-nudge.js`) считает ожидающим и состояние `available` — без скачивания оно работает как было.
Проверка: тест `selfInstalls` (мак — нет, Windows/Linux — да); `node --test test/*.test.js`; снимок карточки в состоянии «доступна» на маке (480 px, заглушка); вживую — у основателя на маке со следующим выпуском после 0.1.19.
